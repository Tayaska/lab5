# Метрики якості моделей класифікації

## Матриця помилок

Матриця помилок (confusion matrix) — це таблиця, у якій рядки відповідають правильним класам, а стовпці — передбаченим. На головній діагоналі знаходиться кількість правильно класифікованих об'єктів, а поза діагоналлю — кількість помилок, тобто скільки об'єктів одного класу модель віднесла до іншого. Матриця помилок показує не лише кількість помилок, а й те, які саме класи модель плутає між собою.

Для бінарної класифікації елементи матриці мають спеціальні назви:
- TP (True Positive) — позитивні об'єкти, правильно визначені як позитивні;
- TN (True Negative) — негативні об'єкти, правильно визначені як негативні;
- FP (False Positive) — негативні об'єкти, помилково визначені як позитивні (хибна тривога);
- FN (False Negative) — позитивні об'єкти, помилково визначені як негативні (пропуск).

## Accuracy

Accuracy (точність, частка правильних відповідей) = (TP + TN) / (TP + TN + FP + FN). Це найпростіша метрика, але на незбалансованих даних вона може вводити в оману. Наприклад, якщо 95 % листів не є спамом, модель, яка завжди відповідає «не спам», матиме accuracy 95 %, хоча не знаходить жодного спаму.

## Precision

Precision (влучність) = TP / (TP + FP). Показує, яка частка об'єктів, віднесених моделлю до класу, справді належить до нього. Висока precision важлива, коли хибні спрацювання дорогі, наприклад у фільтрі спаму, який не повинен блокувати важливі листи.

## Recall

Recall (повнота) = TP / (TP + FN). Показує, яку частку об'єктів класу модель змогла знайти. Висока recall важлива, коли пропуск дорогий, наприклад у медичній діагностиці, де не можна пропустити хворого пацієнта.

## F1-score

F1-score — це гармонічне середнє precision і recall: F1 = 2 · Precision · Recall / (Precision + Recall). F1 високий лише тоді, коли обидві метрики високі, тому вона зручна для незбалансованих даних.

## Усереднення для багатьох класів

У багатокласовій задачі precision, recall і F1 обчислюються для кожного класу окремо, а потім усереднюються:
- **macro** — просте середнє по всіх класах; кожен клас має однакову вагу незалежно від кількості об'єктів. Macro-усереднення чутливе до якості на малих класах.
- **weighted** — середнє, зважене на кількість об'єктів кожного класу (support). Великі класи впливають сильніше.
- **micro** — метрики обчислюються за сумарними TP, FP, FN по всіх класах; для багатокласової задачі micro F1 дорівнює accuracy.

Якщо macro F1 помітно нижчий за weighted F1, це означає, що модель гірше працює на малочисельних класах.

## Classification report

Функція classification_report з бібліотеки scikit-learn виводить precision, recall, F1-score і support для кожного класу, а також accuracy, macro avg і weighted avg. Support — це кількість об'єктів відповідного класу в тестовій вибірці.

## Метрики регресії

Для задач регресії використовують інші метрики: MAE (середня абсолютна помилка), MSE (середньоквадратична помилка), RMSE (корінь із MSE) і коефіцієнт детермінації R², який показує, яку частку дисперсії цільової змінної пояснює модель (1 — ідеальна модель).
